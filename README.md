# WeatherBot

Chatbot desenvolvido em Python com o objetivo de consultar informações
meteorológicas a partir de uma localização informada pelo usuário.

## Objetivo

Este projeto foi desenvolvido como um projeto de aprendizado para praticar:

- Python
- Consumo de APIs REST
- Requisições HTTP
- Manipulação de JSON
- Tratamento de erros
- Estruturação de aplicações
- Git e GitHub

## Funcionamento

O usuário informa uma localização, por exemplo:

> clima em Campinas

O WeatherBot deverá:

1. Interpretar a mensagem do usuário.
2. Identificar a localização informada.
3. Consultar a API de geocodificação.
4. Obter latitude e longitude.
5. Consultar os dados meteorológicos.
6. Processar a resposta JSON.
7. Apresentar as informações ao usuário.

## Tecnologias

- Python 3.12.2
- Open-Meteo API
- Git
